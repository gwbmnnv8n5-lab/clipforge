# 拼影工坊 ClipForge

多模型 AI 视频生成与拼接平台。用法：写分镜 → 每个镜头挑一家模型生成，或者上传 App 里免费生成的片段 → 一键合成成片（转场、配乐、统一比例）。

只依赖 **Python 3.8+** 和 **ffmpeg**，不用装数据库，也不用 Docker。

## 一、安装到 Linux 服务器（一条命令）

方式 A：从 GitHub 安装（推荐，升级只需 `git pull`）
```bash
git clone https://github.com/你的用户名/clipforge.git
cd clipforge && sudo bash install.sh
# 以后升级：cd clipforge && git pull && sudo bash install.sh
```

方式 B：用压缩包

```bash
# 1. 把压缩包传到服务器（在你自己电脑上执行，IP 换成你的）
scp clipforge.zip root@服务器IP:/root/

# 2. 登录服务器后执行
cd /root && unzip -o clipforge.zip && cd clipforge
sudo bash install.sh
```

脚本会自动完成这些事：安装 ffmpeg，复制程序到 `/opt/clipforge`，让你设置登录密码，配置开机自启。

装好后，在云服务器控制台的**安全组里放行 8800 端口**，然后浏览器打开 `http://服务器IP:8800`。

**升级**：以后我给你新版本，重新解压后再执行一次 `sudo bash install.sh`。项目、视频和 Key 都会保留。

**强烈建议加 HTTPS**：如果你有域名，安装 Caddy 后执行 `caddy reverse-proxy --from 你的域名 --to localhost:8800`。否则登录密码是明文传输的。

## 二、第一次使用（推荐流程）

1. **模型设置**：把手里有的 Key 都填上，每家点一下「测试连接」（不消耗额度）。MiniMax 的「额度」填每天能用的条数，比如 3。
2. **项目 → 从示例创建**，展开「🎭 角色与风格设定」，写好画面风格和主角外貌。这两段会自动加到每个镜头前面，换平台生成时人物也尽量保持一致。
3. 点右上角 **⚡ 一键生成全部镜头**。平台会自动把镜头分配给有免费额度的平台，不需要你选平台和模型。
4. 片段生成后会自动出现。不满意的镜头可以再生成一次，在想要的那条上点「用这条」。
5. 右侧「合成成片」：选转场、加音乐，合成后下载。

### ✨ 智能选择是怎么分配的
- **先用每日免费的额度**（MiniMax Token Plan、Hugging Face）：这类额度当天不用就浪费了。
- **再用永久免费的模型**（智谱 CogVideoX-Flash、OpenRouter 免费模型）：不限量，但画质一般、可能排队。
- **再用会过期的试用额度**（Google $300、阿里百炼、火山方舟、Replicate）。
- **最后才用付费额度**：只有在「额度」页打开「付费兜底」时才会用。
- 某一家提交失败（额度用完、Key 失效、参数不支持），自动换下一家。生成过程中失败的，也会自动换一家重试一次。
- 自动选时长：比如要 5 秒，平台只有 10 秒的，就生成 10 秒，合成时自动裁成 5 秒。
- 自动适配提示词：海螺专用的运镜指令 `[Push in]` 会转成中文描述再发给其他平台；海外模型会自动翻译成英文（借用 MiniMax 的文本模型）。
- 顶部徽标「今日免费 ≈ N 条」显示今天还能免费生成多少条，详情在「额度」页。

## 三、怎么把免费额度用到最多

| 来源 | 怎么用 |
|---|---|
| MiniMax Token Plan 视频额度 | 在本平台直接生成 |
| **智谱 CogVideoX-Flash**（官方免费，不限次数，画质一般） | bigmodel.cn 注册 → API Keys → 填到「模型设置」，无需付费 |
| **OpenRouter 免费模型**（如 Wan 2.6:free，有每日频率限制） | openrouter.ai 注册 → Keys → 填到「模型设置」 |
| Google Cloud 新用户 $300（Veo 3.1 / Imagen 4） | 见第四节，按秒计费，Fast 版最省 |
| Hugging Face 免费 ZeroGPU（每天几分钟） | 见第四节，完全免费、不绑卡 |
| Replicate 新账号免费试跑 | 见第四节 |
| 阿里百炼新人免费额度（每个万相模型单独有，90 天有效） | 注册阿里云百炼 → 开通模型 → 创建 API Key，填到「模型设置」 |
| 火山方舟新用户免费额度（Seedance） | 注册火山引擎 → 方舟控制台开通 Seedance → 创建 API Key |
| 即梦 / 可灵 / 海螺 / Vidu **App 里**每天送的积分 | 在 App 里生成后下载，回到镜头点「上传片段」 |
| Google Vids 每月约 10 条 Veo 视频、Runway/Luma 新用户积分等 | 同上，生成后上传 |

各平台的免费额度经常调整，以各自控制台显示为准。请遵守各平台条款，不要批量注册小号，容易封号。

## 四、海外平台怎么开通

### Google Veo（$300 试用金）
新开的 Google Cloud 账号送 $300，90 天内有效。需要绑卡验证身份，但试用期内不会自动扣费。
1. 打开 console.cloud.google.com 注册并开通免费试用，然后新建一个项目。
2. 顶部搜索「Vertex AI API」，点「启用」。
3. 进入「IAM 和管理 → 服务账号 → 创建服务账号」，角色选 **Vertex AI User**。
4. 点进刚建的服务账号，选「密钥 → 添加密钥 → JSON」，会下载一个 .json 文件。
5. 用记事本打开这个文件，把**全部内容**粘贴到拼影工坊「模型设置 → Google Veo」里，保存。

建议优先用 **Veo 3.1 Fast 无声**，最省钱，配乐在合成时加。Imagen 4 Fast 可以用来生成首帧图，每张只要几分钱。

### Hugging Face（完全免费）
1. 注册 huggingface.co，进入 Settings → Access Tokens，新建一个 Read 权限的 Token，填到平台里。
2. 免费账号每天有几分钟 GPU 时长，大约够生成几条短视频。用完后会提示 quota 错误，第二天自动恢复。
3. 内置的是社区维护的 Space，可能排队或下线。在 huggingface.co/spaces 搜 "video"，把想用的 Space ID（例如 `owner/space-name`）填到「额外模型」，平台会自动识别它的参数。

### Replicate（模型超市）
注册 replicate.com，复制 API Token（r8_ 开头）。新账号能免费试跑部分模型，比如 minimax/video-01，次数有限，之后按次付费。网站上任何视频模型都能填进「额外模型」使用。

## 五、小技巧

- **想要竖屏**：给镜头加首帧图，可以上传，也可以点「AI 生成」，比例选 9:16。这样会走图生视频，画面比例跟随首帧，人物长相也更统一。
- **合成比例不一样的素材**：「素材适配」选「模糊背景填充」，横屏素材放进竖屏成片也好看。
- **慢动作**：在片段上点「剪辑」，速度选 0.5x 或 0.75x。也可以设置起点和终点，裁掉不要的部分。
- **平台出了新模型**：到「模型设置 → 额外模型 ID」里填上模型 ID，马上就能用。

## 六、常用命令

```bash
systemctl status clipforge      # 运行状态
journalctl -u clipforge -f      # 实时日志（生成失败时看这里）
systemctl restart clipforge     # 重启
```

数据位置：`/opt/clipforge/data`（数据库和所有视频）。备份时打包这个目录就行。

## 说明

- 各平台接口按官方文档实现。如果某家平台调整了接口，生成时会显示平台返回的原始报错，把报错发给我就能修。
- 平台只接入官方开放接口，不会模拟登录 App，账号安全无风险。
